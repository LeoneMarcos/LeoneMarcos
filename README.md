## What I do

- **AI agents and orchestration:** multi-model workflows where one model plans and another executes, with tools, persistent memory, and MCP servers and clients.
- **RAG pipelines:** ingestion, deduplication, embeddings, vector search, and grounded generation, with quota and cost safeguards.
- **Multimodal and local AI:** OCR combined with vision-language models running locally, plus speech recognition and text-to-speech for voice assistants.
- **Product engineering:** React and TypeScript interfaces, serverless backends, native Android apps in Kotlin, real-time communication with WebRTC, and Python automation.

## Client Work

### [Empire Eagle Construction](https://empireeagleconstruction.com/)

A website for a New Jersey home renovation company, built to turn visitors into conversations: real project galleries, client reviews, and a short form that opens WhatsApp with the message already prepared.

https://github.com/user-attachments/assets/bf8931ea-f7e3-452e-acd9-0fb115d5af3c

- **Problem:** The company had an outdated site that did not show its real work. It needed a clear presentation and a direct path from a visitor to an estimate request, without accounts or a backend.
- **Engineering:** Built with React 19, TypeScript, Vite, and Tailwind CSS, deployed on Cloudflare Workers. Includes typed photo galleries by service, client reviews with pause-on-interaction, and keyboard-accessible controls. Covered by unit and end-to-end tests with Playwright.
